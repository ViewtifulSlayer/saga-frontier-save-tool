Keyboard controls

Every control here is reachable without a mouse. The character detail card names its roster position, so you can tell which row you are on when the table is off-screen.

Keys Where Action
Tab / Shift + Tab Anywhere Next or previous control
Enter or Space Drop zone Open the file picker
Enter or Space Slot button Load that slot
↓ / ↑ Roster row Select the next or previous character. Focus stays on the row and the page does not jump to the detail card, so you can walk the whole roster.
Home / End Roster row Select the first or last character
Enter or Space Roster row Select the character and scroll to the detail card

Arrow keys stop at the ends of the roster rather than wrapping. They move focus and selection together, so the row with focus is the character in the card. Tab still steps through the rows without changing the selection.
